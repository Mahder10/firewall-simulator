# Firewall Simulator (Java)

This project simulates a basic firewall system that allows or blocks IP addresses based on predefined security rules.

## Features
- IP allow/deny list
- Simple rule-based filtering
- Simulated firewall decision-making

## Purpose
To understand how firewalls control network traffic and protect systems from unauthorized access.

## Cybersecurity Concept
Firewalls are a core part of network security used to filter incoming and outgoing traffic based on security rules.

## Technologies Used
- Java

## Learning Outcome
- Understanding access control
- Basic decision-making systems
- Introduction to network security concepts
